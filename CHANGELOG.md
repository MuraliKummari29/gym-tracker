## [Unreleased]

### Added
- Local SQLite database with versioned migrations and an 876-exercise seed.
- Workout logger with per-set weight, reps and completion.
- Exercise library filtered by equipment, with two-frame animated demos and instructions.
- Challenge tracker with 75-Day Hard, Soft and Medium presets and a progress grid.
- Diet targets from Mifflin-St Jeor BMR, activity level and goal.
- Unit tests for nutrition, dates and challenge presets; CI on GitHub Actions.
